# 5 — EPBS (End-Product Breakdown Structure)

**Arcadia level:** EPBS. **Maturity:** partial — items that exist are fully identified; items
not yet built are listed with their acceptance criteria rather than omitted.

The configuration items the programme delivers or consumes, each with an owner and an identity.
An item without an identity cannot be reproduced, and an item without an owner has nobody to
fix it.
